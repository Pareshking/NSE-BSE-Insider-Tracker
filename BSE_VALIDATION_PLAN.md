# BSE validation plan

BSE certification is independent of NSE. The legacy combined workflow is diagnostic only.

Current test gate: 90-day BSE acquisition for Insider, Bulk and Block. Inspect actual distinct dates, row counts, native columns, pagination/completeness and intra-BSE duplicates. Rights and Preferential remain pending-detail items and do not block the working categories.

Mandatory loop: test -> inspect real output -> identify defect -> fix -> retest -> verify -> update documents -> continue.
