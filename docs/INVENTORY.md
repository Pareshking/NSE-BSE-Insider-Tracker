# Inventory: what is built and working (21 Nov 2026)

Read from the code on `main` (not from the other docs). "Held" date ranges are measured from R2 on 21 Nov 2026 with
the read-only `clean-peek` mode `TABLE_RANGES` (min/max of each date column, rows per table); fetch ranges from the
raw coverage audit (`scripts/raw_coverage.py`). Where the code does not settle a point it says so.

Conventions used below:
- **NSE BASE** = `https://www.nseindia.in` (`collectors/nse_events/client.py`); **BSE API** =
  `https://api.bseindia.com/BseIndiaAPI/api/` (`collectors/bse/client.py:66`).
- **Raw**: every response is kept write-once at `raw_v2/{source}/{dataset}/blobs/{sha[:2]}/{sha}.{ext}` with a fetch
  record under `fetches/{date}/` (`insiders_clean/raw_store.py`).
- **Schedules** (UTC → IST): NIGHTLY = `r2-storage.yml` `0 18 * * 1-5` (23:30 IST Mon–Fri, backup 04:30 IST);
  NSE-EV = `nse-events.yml` `0 16 * * 1-6` (21:30 IST Mon–Sat, backup 01:00); ANN = `announcement-collect.yml`
  `15 17 * * *` (22:45 IST daily); MF = `mf-portfolios.yml` `17 4 11-16 * *` (09:47 IST, 11th–16th);
  INDUSTRY = `industry.yml` `43 2 * * *` (08:13 IST). `nightly-watchdog.yml` re-runs a dropped NIGHTLY/NSE-EV.
- Clean tables keep rows from the product start **8 Oct 2025** (`insiders_clean/pipeline.py:25`); archives may
  hold older rows that came inside a filing.

## 3. Reuse

- **Layout.** Top-level packages `collectors/` (`bse/`, `nse_events/`, `mf_portfolios/`), `insiders_clean/` (parsers and
  clean steps), `scripts/` (flat runners, no `__init__.py`), `streamlit_app/` (the site). No `pyproject.toml` or
  `setup.py`: put the repo root on `PYTHONPATH`. Most scripts and some collectors insert the root and `scripts/`
  into `sys.path` themselves.
- **Imports that work from outside** (checked with Python 3.13, `-I`, root on the path), pulling in only pandas,
  numpy and pyarrow: `from collectors.bse.parsers import parse_actions`; `from collectors.nse_events.parsers import
  parse_sast`; `from insiders_clean.prices import parse_udiff`; `from insiders_clean.mf_holdings import parse_workbook`;
  `from insiders_clean.industry import parse_nse, parse_bse`; `import insiders_clean.results`. The clients
  (`collectors.*.client`) need requests. `collectors.nse_events.run_daily` imports boto3 through `scripts/r2_writer.py`.
- **Python** 3.12 on the workflows (3.11 compile check; the site runs 3.11). `requirements.txt`: boto3, requests,
  pandas <3, pyarrow, html5lib, lxml, beautifulsoup4, selenium, bseindia, bse, nse[server], pymupdf, xlrd, openpyxl;
  Playwright is installed separately by the fund-house workflows; the site adds streamlit 1.67.0.
- **Parsers are pure** (bytes/JSON in, DataFrame out; no network, R2 or environment): `collectors/nse_events/parsers.py`,
  `collectors/bse/parsers.py`, `insiders_clean/prices.py`, `results.py`, `industry.py`, `mf_holdings.py`. Not pure:
  the clients and `collectors/mf_portfolios/apis*.py`/`find.py` (network by design); `houses.py` reads today's date at
  import; `insiders_clean/raw_store.RawStore` reads `R2_BUCKET_NAME`; `scripts/nse_insider.py` has import side effects.
- **Storage.** Cloudflare R2 over the S3 API (boto3), Parquet with zstd for every table, raw responses write-once
  (`IfNoneMatch='*'`, text gzipped). No SQLite or DuckDB.
- **Politeness.** NSE client: 3–5 s random pause between calls, 3 retries on 5xx, stops on 401/403/429 (`Blocked`), never
  parallel. BSE client: 4–6 s pause, 3 retries, stops on 401/403/429 (then falls back to an in-page request once);
  parallel only where BSE is slow to answer, 4 clients at 1–2 s each with the first refusal stopping all (industry,
  shareholding XBRL). Fund houses: no pause, one request at a time per house, up to 6 houses at once; AMFI one
  request per day asked. Filing text: up to 4 downloads per host at once with a 0.3 s pause. User-Agents are desktop
  Chrome strings.
