# Lanes of the announcement reader (scripts/announcement_reader.py). Changing a model is a change to this file.
# One line a lane: "name: provider:model, ..." (a different provider on each line). Every lane takes the next
# filing, so the providers read different filings at once; within a lane the next model is used when one is
# busy, refused, too slow or at its daily limit; a filing a lane cannot read goes to another lane. When nothing
# is left to read, an idle lane reads again a filing another provider read ("2 readers agree").
# Picked 13-14 Oct 2026 from the 24-filing test and the first live run (docs/ANNOUNCEMENT_READER.md).
